# What the UFO?!

Phase 0 foundation and Phase 1 frontend for a cinematic Cornish paranormal community.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

This phase is intentionally frontend-only. Encounter submission, authentication, comments, moderation, persistence, and community posting are not active.
